# GamesLab

A social gaming discovery and community platform inspired by Letterboxd, built as a 10-day software engineering learning project.

## Vision

GamesLab enables players to:
- Discover and search video games
- Rate and review games
- Create personal gaming lists
- Follow other users and view activity
- Maintain gaming profiles
- Create and join gaming communities
- Participate in community text channels

## Technology Stack

- **Framework:** Next.js (App Router) + TypeScript
- **Styling & UI:** Tailwind CSS + shadcn/ui
- **Backend & Database:** Supabase (PostgreSQL, Auth, Realtime, Row Level Security)
- **Version Control & Deployment:** Git, GitHub, Vercel
